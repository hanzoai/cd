# External URL Links

Hanzo CD automatically generates clickable links to external pages that your application exposes.
This is usually done via detecting hosts / URLs from your `Ingress` resources.

## Add external URL

You can add additional external links to Hanzo CD dashboard. For example
links to monitoring pages or documentation, instead of just ingress hosts or other apps.

Hanzo CD generates clickable links to external pages for a resource based on per resource annotation.

Example:
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-svc
  annotations:
    link.apps.hanzo.ai/external-link: http://my-grafana.example.com/pre-generated-link
```
![External link](../assets/external-link.png)

The external link icon will be visible for respective resource on Hanzo CD application details page.

![External link](../assets/external-link-1.png)

## Ignore autogenerated external URLs

If an ingress object should be ignored by Hanzo CD's autodetection of external URLs, such as a dummy ingress
pointing to a 404 page, you can add the `apps.hanzo.ai/ignore-default-links: "true"` annotation. This will
remove any links inferred from the ingress spec from the Hanzo CD UI. Any links added by `link.apps.hanzo.ai`
annotations are unchanged.

Example:
```yaml
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  annotations:
    link.apps.hanzo.ai/external-link: https://optional.show-me-instead.example.com/
    apps.hanzo.ai/ignore-default-links: "true"
spec:
  rules:
  - host: dont-show-me.internal.example.com
    ...
```
