# `cd admin app` Command Reference

## cd admin app

Manage applications configuration

```
cd admin app [flags]
```

### Examples

```

# Compare results of two reconciliations and print diff
cd admin app diff-reconcile-results APPNAME [flags]

# Generate declarative config for an application
cd admin app generate-spec APPNAME

# Reconcile all applications and store reconciliation summary in the specified file
cd admin app get-reconcile-results APPNAME

```

### Options

```
  -h, --help   help for app
```
