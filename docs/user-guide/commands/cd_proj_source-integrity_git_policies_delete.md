# `cd proj source-integrity git policies delete` Command Reference

## cd proj source-integrity git policies delete

Delete a git source integrity policy

```
cd proj source-integrity git policies delete PROJECT POLICY_ID... [flags]
```

### Examples

```
  # Delete git policy at index 1 and 3 from project named PROJECT
  cd proj source-integrity git policies delete PROJECT 1 3
```

### Options

```
  -h, --help   help for delete
  -y, --yes    Skip explicit confirmation
```
