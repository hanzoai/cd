{{- if .Values.server.ingress.enabled }}

   or via the ingress host(s) configured in server.ingress.hosts:
   {{- range .Values.server.ingress.hosts }}
   - {{ .host }}
   {{- end }}

2. The initial admin password lives in the hanzocd-secret Secret once the
   server bootstraps it:

   kubectl get secret -n {{ .Release.Namespace }} hanzocd-secret -o jsonpath='{.data.admin\.password}' | base64 -d

3. Log in with the CLI:

   cd login <server-address>
